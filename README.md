Fast React Pizza

A pizza ordering website. no login needed just enter your name. The Menu with all available pizzas are shown. menu is from an API(so menu changes). from the menu you can order pizza change the no of pizzas. all pizzas are added to the cart.from cart you can place the order orderID will be created you can place the order on priority by paying few extra price on top of cart price.enter your phone number and address. The order shows at which time your order will be delivered and how much to pay for on delivery.a GPS location share option is availabe so as to calculate delivery time correctly.No payment system because only pay on delivery available.
